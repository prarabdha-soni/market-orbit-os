# Expansion OS

Build a production-quality web application called Rocket-Loop.

Rocket-Loop is an Autonomous Market Expansion OS / AI Expansion Manager for Indian physical-product brands.

The product should feel like a serious, premium B2B AI operating system used by a growth leader — not like a generic AI chatbot, CRM, marketing dashboard, or template SaaS.

The visual reference is the attached Rocket-Loop product UI concept: a clean enterprise dashboard with a dark left navigation rail, spacious white/light-gray workspace, indigo/purple AI accents, cards, maps, tables, charts, timelines, agent status indicators, and conversational execution views.

The product should feel inspired by high-end products such as Linear, Ramp, Stripe, Clay, Palantir and modern AI-agent interfaces, while remaining original.

IMPORTANT:
This is a working product prototype, not a marketing website.

The central product concept is:

User gives Rocket-Loop an expansion goal → Rocket-Loop understands the business → discovers the market → decides where to act → executes outreach → coordinates samples/orders → learns from outcomes.

The core product loop is:

UNDERSTAND → DISCOVER → DECIDE → EXECUTE → LEARN
